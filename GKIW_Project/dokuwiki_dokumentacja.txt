==== Streszczenie ====
Projekt polega na stworzeniu w pełni trójwymiarowej gry planszowej "Go". Aplikacja symuluje trójwymiarowe środowisko ze stołem (goban) do gry, a także otoczenie takie jak trawa i kwiaty w tle. Głównymi założeniami projektu są: wczytywanie i wyświetlanie modeli 3D w formacie GLB, własny model oświetlenia z tłumieniem i cieniami, oraz interaktywny wybór pola do położenia kamienia na planszy z wykorzystaniem promienia (Raycasting) z pozycji kamery zależnie od miejsca kliknięcia myszą. Całość zaimplementowana jest z użyciem języka Python, biblioteki ModernGL i matematyki dla OpenGL z pakietu PyGLM.

=== Słowa kluczowe: ===
Go, Python, ModernGL, Raycasting, PyGLM, GLSL, Oświetlenie, Shadow Mapping, glTF (GLB).

==== Techniki wizualizacji wykorzystane w projekcie ====

  - Modele 3D wczytywane z formatu plików binarnych glTF (.glb).
  - Teksturowanie
    - Tekstury osadzone i wczytywane z modeli ``.glb``.
  - Oświetlenie
    - Oświetlenie ambientowe i rozproszone (diffuse).
    - Tłumienie oświetlenia (Attenuation) z użyciem stałych ``constant``, ``linear``, ``quadratic`` wyliczane dla dystansu fragmentu od źródła światła (w pliku ``custom_light.glsl``).
    - Mapowanie cieni (Shadow Mapping) realizowane poprzez dodatkowy przebieg renderowania głębi światła ze źródła światła (w pliku ``depth.glsl``) oraz filtrację PCF (Percentage-Closer Filtering) do łagodzenia krawędzi.
  - Elementy losowości
    - Losowe rozmieszczenie modeli w tle - pozycje ździebeł trawy oraz kwiatów wokół stołu losowane w klasie ``Scene`` z biblioteki standardowej ``random``.
  - Szadery -> GLSL
    - ``custom_light.glsl``: implementacja oświetlenia punktowego z teksturami z modelu.
    - ``custom_light_solid.glsl``: implementacja oświetlenia punktowego dla brył jednolitych barwnie.
    - ``depth.glsl``: program dedykowany do wyliczania głębi w perspektywie światła na potrzeby generowania map cieni.
  - Przechwytywanie interakcji
    - Implementacja raycastingu (w ``utils/raycasting.py``) – odwracanie rzutu perspektywicznego i macierzy widoku do obliczenia promienia (ray) na podstawie współrzędnych ekranu, w celu detekcji uderzenia na nieskończonej płaszczyźnie na wysokości planszy go.

==== Wykorzystanie gotowych bibliotek modeli ====

  - Zewnętrzne oprogramowanie do modelowania [[gk:blender|Blender]] zostało użyte do wygenerowania stołu, kamieni, trawy oraz kwiatów, a następnie odpowiedniego wyeksportowania zasobów do formatu ``.glb`` by ułatwić i zoptymalizować wczytywanie modeli w środowisku Python.
  - Skrypt ``fix_glb.py`` został stworzony w celu oczyszczania modeli z rozszerzeń specyficznych dla niektórych programów (nieobsługiwanych przez domyślne loadery).

==== Animacje ====
W grze interakcja nie zachodzi poprzez bezpośrednie animacje samych modeli (brak animacji szkieletowych czy interpolacji węzłów czasu), natomiast występuje ruch kamery, w pełni kontrolowany przez użytkownika podczas gry (np. orbita wokół stołu). Transformacje (skala i przesunięcie) obiektów wyliczane są w każdej ramce.

==== Tryb demo ====
Aplikacja z zasady ma stanowić interaktywne narzędzie. Z racji charakteru gry planszowej, środowisko otoczenia może być generowane całkowicie losowo podczas startu. Użytkownik decyduje w pełni, gdzie trafiają kolejne kamienie i pod jakim kątem analizuje planszę.

==== Kluczowe fragmenty kodu ====

Raycasting - rzutowanie kliknięcia na świat 3D:
<code python utils/raycasting.py>
    # Okno -> NDC (-1 do 1)
    view = glm.lookAt(camera_pos, camera_target, up_vector)
    viewport = glm.vec4(0.0, 0.0, float(window_size[0]), float(window_size[1]))

    win_y = float(window_size[1]) - float(y)
    near_point = glm.unProject(glm.vec3(x, win_y, 0.0), view, projection, viewport)
    far_point = glm.unProject(glm.vec3(x, win_y, 1.0), view, projection, viewport)

    ray_origin = near_point
    ray_direction = glm.normalize(far_point - near_point)

    # Obliczenie odległości na promieniu
    t = (TABLE_HEIGTH - ray_origin.y) / ray_direction.y
    hit_point = ray_origin + ray_direction * t
</code>

Oświetlenie na poziomie GLSL:
<code glsl assets/custom_light.glsl>
    // Kierunek światła
    vec3 tableLightDir = normalize(tableLightPos - world_pos);
    float tableDiff = max(dot(norm, tableLightDir), 0.0);
    
    // Tłumienie światła na podstawie dystansu!
    float distance = length(tableLightPos - world_pos);
    float attenuation = 1.0 / (constant + linear * distance + quadratic * (distance * distance));
    vec3 tableLighting = tableDiff * tableLightColor * tableLightPower * attenuation;
</code>

Wyliczanie Cienia (Shadow Mapping) z filtrowaniem (PCF):
<code glsl assets/custom_light.glsl>
    float currentDepth = projCoords.z;
    float bias = max(0.005 * (1.0 - dot(norm, tableLightDir)), 0.001);
    vec2 texelSize = 1.0 / textureSize(shadowMap, 0);
    
    for(int x = -1; x <= 1; ++x) {
        for(int y = -1; y <= 1; ++y) {
            float pcfDepth = texture(shadowMap, projCoords.xy + vec2(x, y) * texelSize).r; 
            shadow += currentDepth - bias > pcfDepth ? 1.0 : 0.0;        
        }    
    }
    shadow /= 9.0;
    tableLighting *= (1.0 - shadow);
</code>

==== Pomiary czasu generowania sceny ====
Pomiary profilowania można zamieścić w tym miejscu. Ponieważ środowisko polega głównie na bibliotece z akceleracją GPU (ModernGL), proces CPU w większości poświęcony jest wywołaniom systemowym oraz odświeżaniu pozycji kamery - przez to aplikacja potrafi wygenerować scenę utrzymującą stabilne i wysokie framerate'y (> 60 FPS).

==== Podsumowanie ====
Zaimplementowana została w pełni działająca aplikacja graficzna trójwymiarowej gry Go. Oświetlenie obiektów (Blinn-Phong z Attenuation i mapowaniem cieni) i interakcja przez "Raycasting" pozwalają na płynną i intuicyjną zabawę. Model oświetlenia wraz ze środowiskiem sprawiają, że scena zyskuje naturalny i wiarygodny wygląd na wyrenderowanej z pomocą języka Python i API ModernGL płaszczyźnie.
